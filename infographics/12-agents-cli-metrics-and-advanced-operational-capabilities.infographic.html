⚖️Coding Agent vs Agent Mode

Coding Agent

  • Runs within GitHub
  • Creates branches, commits, PRs
  • Asynchronous, background
  • GitHub Actions environment
  • Delegated tasks
VS

Agent Mode

  • Runs in the IDE
  • Interactive multi-step edits on local files
  • Local / IDE environment
  • Iterative refinement
❗
Do not confuse them. Critical for exam scenarios.
