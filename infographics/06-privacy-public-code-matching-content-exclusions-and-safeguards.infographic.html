🔏 Privacy, Public Code Matching & Safeguards

Privacy-first and policy-controlled, but not absolute. Developers stay responsible.

5safeguards

🧱Data handling boundaries

📦

Processing scope

Prompts, context and completions are processed to respond, not broadly shared.

🚷

No cross-user sharing

Private code is not shared with other users or orgs.

📑

Enterprise guarantees

Business and Enterprise get contractual data protection.

🎯

Controlled usage

Used for responses and service improvement within bounds.

❗
Copilot does not use your private repo code to train models in a way that makes it accessible to others.

⏳IDE vs chat retention

IDE usage

  • Prompts not retained for model training after completion
  • Temporary processing for service function
VS

Chat / web usage

  • Conversations may be retained for continuity
