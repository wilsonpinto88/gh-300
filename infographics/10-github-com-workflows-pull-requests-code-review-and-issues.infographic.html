⚖️Can vs cannot

Copilot can

  • Summarise PRs
  • Explain changes
  • Suggest code changes
  • Create issues from plain language
  • Open a PR for an assigned issue
VS

Copilot cannot

  • Approve or reject PRs
  • Count toward required approvals
  • Merge or enforce repo rules
  • Understand full architecture
  • Work across repositories
