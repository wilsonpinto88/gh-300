⚖️Spaces vs Knowledge Bases

SpacesKnowledge Bases
PurposeFocused, task-specificLarge-scale, org-wide docs
PriorityAccuracy (small, curated)Breadth (large sets)
Created byIndividual users (or orgs)Typically org level
PrecisionHigherLower with large context
FormatMixed sources + instructionsUsually markdown in repos
