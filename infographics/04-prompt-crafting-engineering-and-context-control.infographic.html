🎯Zero, one and few-shot

0️⃣

Zero-shot

Instruction only, no examples.

1️⃣

One-shot

One example guides output.

🔢

Few-shot

Several examples set patterns. Reduces ambiguity, anchors style, improves consistency.

🚫Common mistakes

🌫️

Ambiguous prompts

Unpredictable results.

🕳️

Missing context

Copilot cannot infer it.

🔒

Over-specification

Limits useful variation.

🙈

Ignoring context

Open files and selection unused.

⏹️

Not iterating

Accepting poor output.

📋Practical patterns

  • ✅Start general, then refine
  • ✅Use examples
  • ✅Break down tasks
  • ✅Specify scope: file, function, context
  • ✅Ask for structure: steps, code, explanation
