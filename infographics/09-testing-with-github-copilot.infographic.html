💬Inline Chat vs chat modes for testing

Inline Chat

  • Tests for selected code
  • Quick iteration in current file
  • Small, focused scenarios
VS

Chat modes

  • Ask: plan tests, no file changes
  • Edit: create or update test files across files
  • Agent: create project, generate, run, fix failures; picks context itself
