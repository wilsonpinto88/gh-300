👻Inline suggestions (ghost text)

🧬

Context-based

Uses surrounding code, comments and naming.

🎨

Adaptive

Follows your formatting and patterns.

✂️

Granular acceptance

Accept all, part, or ignore.

🌊

Low friction

No explicit prompt, stay in flow.

Related

🔀

Multiple suggestions

Cycle alternatives in the editor.

🔮

Next edit suggestions

Predicts where the next change goes, not just what to type.

💬Chat vs Inline Chat

Copilot Chat

  • Conversation panel
  • Uses open files, selection, workspace
  • Debug, plan, structured refactor
VS

Inline Chat

  • Inside the editor
  • Only selected code or current file
  • Small fixes, targeted refactors

🤖Edits, Agent and Subagents

🗂️

Copilot Edits

Several files in one operation. You review and approve.

🚀

Agent mode

Plans, executes, iterates. May suggest terminal commands and use tools.

🧑‍🤝‍🧑

Subagents

Own context window, focused tasks, results return to main session.
