🛠️Agent Mode, Copilot Edits and MCP

🤖

Agent Mode

Plans and runs multi-step work in the IDE: edits files, runs commands and tests, iterates on errors.

✏️

Copilot Edits

Multi-file changes you review and accept or discard as a working set.

🔌

MCP

Model Context Protocol servers add tools and data, such as the GitHub MCP server.

🧑‍⚖️

You approve

Tool calls and terminal commands need confirmation unless you allow them.

🧵Sub-agents: delegate for optimized context

1Main agentowns your conversation
→
2Delegatesa self-contained task via runSubagent
→
3Sub-agentworks in its own context window
→
4Returns resultonly the summary comes back
🪶

Why: smaller main context

Searching dozens of files happens in the sub-agent, so the main conversation keeps only the findings.

📦

No inherited history

Give the goal, context, allowed actions and expected result in the task itself.

🗃️Agent sessions

💻

Local

Agent Mode in your IDE, on your files, watched live.

⌨️

CLI / background

Copilot CLI sessions. Resume with --resume or --continue.

☁️

Cloud

Copilot cloud agent on GitHub. Works on a branch and opens a draft PR.

📋

Manage

The sessions view lists them: monitor, open, resume, hand off local work to the cloud.

🔁
Renamed: "Copilot coding agent" is now Copilot cloud agent in GitHub docs. Older questions may still say coding agent. Same feature.

✨Spaces, Spark and PR summaries

🗂️

Spaces

Curated, shareable context (repos, files, issues, notes) that grounds Copilot answers.

⚡

Spark

Builds small web apps from natural language, with hosting and live preview.

📄

PR summaries

Copilot drafts the PR description: what changed, why, and where to look.

🔍

Code review

Comments with suggested changes, guided by your instructions files.

⚠️
Spark retirement: since August 4, 2026, Spark on github.com takes no new users or apps. Existing users can export until August 31, 2026, and deployed apps keep running. The exam guide still lists Spark, so know what it does.
