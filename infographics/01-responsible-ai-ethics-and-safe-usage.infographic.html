⚠️Five core risks of AI-assisted coding

🌀

Hallucinations

Confident but wrong output, including subtle logic bugs that pass a quick review.

🔓

Security risk

Injection flaws, weak crypto, unsafe input handling.

⚖️

IP / licensing

Code may resemble public repos. Check licence and attribution.

💧

Data leakage

Prompts and context can expose secrets, credentials, business logic.

🪑

Over-reliance

Accepting what you do not understand adds technical debt.

⚠️
AI-generated output is untrusted until validated.

🎲Deterministic vs probabilistic

Traditional software (deterministic)

  • Same input → same output
  • Fully predictable
  • Rule-based
VS

Copilot (probabilistic)

  • Same input → different possible outputs
  • Predicts the most likely answer
  • Does not verify correctness
  • Looks right ≠ is right
❗
Copilot does not know the correct answer. It generates the most likely answer.

🚧Limitations of generative AI

🔭

Limited context window

Sees only part of the codebase.

🧩

Context dependency

Weak naming or missing files lower quality.

📅

Outdated knowledge

Newer APIs and practices may be missing.

📊

Training-data bias

Popular languages are stronger than niche ones.

🧠

No true understanding

Predicts patterns, not business intent.

👁️What Copilot can see

🎯

Primary

📂

Additional

Open files, referenced symbols, selected code

🚫

Missing

💡
Open relevant files, reference specific functions, cut noisy context.

🌀Hallucinations and non-determinism

👻

Non-existent APIs

References functions or libraries that do not exist.

🗣️

Wrong explanations

Sounds correct, logically wrong.

🧱

Invented assumptions

Assumes behaviour not in the codebase.

⚠️
The danger is not that Copilot is wrong. It is convincingly wrong.

⚖️The six Responsible AI principles

🤝

Fairness

Training data bias. Review sensitive logic such as identity and access control.

🔧

Reliability & Safety

Probabilistic code can hide failures. Test edge cases.

🔐

Privacy & Security

Never put secrets in prompts or shared context.

🌍

Inclusiveness

Better for popular languages. Clear structured inputs help.

🔎

Transparency

Copilot is a tool, not an authority. It may be wrong.

👤

Accountability

Humans own validation, testing and approval. It never executes or deploys.

🧰Mitigation strategies

🚪

Guard inputs

No secrets in prompts. Redact and minimise context.

🙋

Human in the loop

Review, validate, understand.

🛡️

Secure by default

Parameterised queries, validation, least privilege, trusted libs.

🔬

Verify and scan

Tests + code scanning + dependency checks + linters.

📏

Governance

Policies, audits and usage rules.

🔁

Feedback loop

Capture recurring issues and improve prompts.

Pre-merge checklist

  • ✅No sensitive data introduced
  • ✅Unit and integration tests run
  • ✅Security checks and code scanning done
  • ✅Authorization and error-handling paths validated
  • ✅Aligned with project standards

🌱Ethical AI in practice

  • ✅Document limitations of AI-generated code
  • ✅Review all output before production
  • ✅Keep clear ownership of decisions and changes
  • ✅Validate with tests
  • ✅Follow organisational policy and compliance
💡
Ethical AI = technical controls + process controls (review, governance, accountability).
